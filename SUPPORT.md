# Support

Use **Setup help** for sanitized installation questions, **Bug report** for a
reproducible defect, and **Feature request** for a roadmap proposal.

Before opening an issue:

1. Run `npm run verify` from the repository root.
2. Check `docs/TROUBLESHOOTING.md` and `docs/DEVELOPMENT.md`.
3. State whether you are using the zero-account demo, BFF, Shopify theme, or
   Customer Account extension.
4. Remove credentials, shop and account identifiers, customer data, private
   URLs, catalog exports, and production responses.

Community support covers this public reference implementation. It does not
provision a hosted Agent Core tenant, operate Shopify, return real freight
rates, inspect a private merchant environment, or provide a response-time SLA.

Report suspected vulnerabilities through `SECURITY.md`, not a public issue.
